# Hotel Management System

A hotel management system built in Python using text files for data storage.

Built as my Class 12 Computer Science project.

## Features
- Room management and room booking
- Guest booking records
- Restaurant menu and ordering
- Sports activities menu
- Gaming menu
- Bill generation

## Data Files
The program stores its data in text files:
- `rooms.txt` - room details
- `bookings.txt` - guest bookings
- `restaurant_menu.txt` - restaurant items and prices
- `sports_menu.txt` - sports activities and prices
- `gaming_menu.txt` - gaming options and prices
- `bills.txt` - generated bills

## How to Run
1. Install Python 3
2. Download `hotel_management.py` (and the `.txt` files, if included)
3. Open a terminal in that folder
4. Run: `python hotel_management.py`

## Technologies
- Python 3
- File handling (text files)
